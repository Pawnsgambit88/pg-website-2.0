# Analytics and Product Measurement

Do not optimize only for page views or account creation.

## Funnel events
- `event_viewed`
- `find_game_started`
- `registration_started`
- `registration_completed`
- `payment_started`
- `payment_completed`
- `waitlist_joined`
- `event_checked_in`
- `pairing_viewed`
- `result_submitted`
- `event_attended`
- `player_returned_21d`

## Community metrics
- first-game conversion
- registration → attendance
- first-timer → second attendance within 21 days
- repeat-opponent rate
- number of distinct opponents per active player
- +1/referral conversion when implemented
- event fill time
- waitlist conversion

## Privacy
Prefer first-party event collection and pseudonymous user IDs. Do not send phone, email, DOB or payment identifiers to analytics. Consent requirements must be reviewed for the selected analytics product.
