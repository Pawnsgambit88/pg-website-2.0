# Accessibility

Target WCAG 2.2 AA.

Required:
- keyboard access to every action
- visible focus states
- semantic heading order
- skip link
- labels for all form controls
- alt text managed in CMS
- decorative images have empty alt only by explicit choice
- carousel controls keyboard accessible and never auto-advance essential information
- pause/disable autoplay where required
- reduced-motion implementation
- touch targets at least practical mobile size
- no meaning conveyed by copper/green alone
- error messages programmatically connected to fields
- status updates exposed through appropriate live regions where needed
- dialogs return focus to the trigger

QA must include keyboard-only, VoiceOver/Safari, NVDA/Firefox or Chrome, 200% zoom and 320px layout.
